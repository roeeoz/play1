# node-hello-world

A minimal Node.js example that prints `Hello World` to stdout.

## Prerequisites

Node.js must be installed. Verify with:

```
node --version
```

## Navigate

```
cd node-hello-world
```

## Install

```
npm install
```

(No dependencies — this confirms your Node.js toolchain is working.)

## Run

Using Node directly:

```
node index.js
```

Using npm:

```
npm start
```

Both commands print `Hello World` to stdout and exit with code 0.
