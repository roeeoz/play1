# TypeScript Setup Example

A minimal reference showing how to write and run a TypeScript script.

## Prerequisites

- Node.js **≥ 18** ([download](https://nodejs.org/))

## Install

```bash
npm install
```

## Run

```bash
npm start
```

## Expected Output

| Command | Output | Exit code |
|---------|--------|-----------|
| `npm start` | `Hello, World!` | `0` |
