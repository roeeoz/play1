# Claims glossary

- **Invoice**: a bill issued for one billing period; never "bill" or "receipt" in code.
- **Credit note**: a negative invoice that corrects an earlier one.
- **Billing period**: a calendar month, written `YYYY-MM`.
- **Net amount**: before tax; **gross amount**: after tax.

Name variables, functions and CSV headers with these terms.
