Choices made in this set

  • Every form state except Default shows "English" as the selected language, so the ten form pages can be compared one-to-one (structure, open branch 5).
  • The language is optional, so there is no language error state (Q2). The form keeps its five approved states.
  • The dropdown is the browser's native select with a CSS-drawn chevron. No new component, icon or font was added (R9). The open list is the browser's own list, which you can try in the prototype.
  • The sample email address, error messages and all other copy are unchanged from the approved screens.
  • The brand green applies to the Sign-up form only. The hover shade is #086848, and the disabled "Subscribing…" button is #8cc9b5. Welcome and Confirmation keep the approved blue (R6).
