Choices made in this prototype

This concept

  • The outline is a compact “Start from” segmented control inside the composer box, right under the description; replacing typed text asks in a one-line strip under it.

Interactions chosen

  • Outline choice is one radio group: Blank, New capability, Change to an existing screen; Blank is selected when the page opens.
  • Into an empty box (or one holding only unedited page headings) a pick fills the headings at once, with no question.
  • Over text the PO typed, the pick shows as pending and the confirmation asks on the spot: “Keep my text” (selection goes back) or “Replace text”.
  • “Replace text” is the error tone of Halo’s destructive dialog buttons, not a primary action: it discards typed text.
  • Blank clears only headings the page put in; over typed text it changes nothing and asks nothing.
  • Headings are Markdown “## ” lines: New capability → Problem, Users, What they can do, Out of scope; Change to an existing screen → Screen today, What changes, Why, Out of scope.

Prototype only

  • No scripts: picks are links between state pages; on “outline selected”, “Change to an existing screen” shows its headings through an anchor.
  • Typing is not simulated: a dashed note on step 02 jumps to step 03.
  • Cancel, Create epic and the Halo logo lead to the Workspace, which has no page: here they return to this wireflow.
  • The Assistant font is not in the checkout, so pages draw in the stack’s system-ui fallback.
