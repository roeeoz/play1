New Epic page offers a starting outline

Every screen and state of the approved inventory, drawn from prototype concept A (Compact) at desktop 1280×720, landscape. The product has no phone layout, so there are no phone pages.

A “Start from” outline choice (Blank, New capability, Change to an existing screen) now sits inside the box under the description, and picking an outline over typed text asks on the spot before replacing it.

Choices and assumptions

  • Drawn from concept A’s pages; the rest of the page and the sidebar are as they are today, copied from NewEpicPage.css, HaloShell.css and HaloSidebar.css.
  • The outline choice is one radio group; a pick into an empty box (or one with only unedited page headings) fills the headings at once with no question.
  • Headings are Markdown “## ” lines: New capability → Problem, Users, What they can do, Out of scope; Change to an existing screen → Screen today, What changes, Why, Out of scope.
  • Confirmation: the pending outline shows a dashed outline; “Keep my text” returns the selection to the previous outline; “Replace text” uses the error tone of Halo’s destructive dialog buttons because it discards typed text.
  • Blank clears only headings the page put in; over typed text it changes nothing and asks nothing.
  • Links between pages follow the journey where a state page exists (Blank ⇄ New capability); Keep my text and Replace text lead to states the inventory does not draw, so they are not links. Cancel, Create epic and the Halo logo go to the Workspace, which has no page: here they return to this gallery.
  • Create epic keeps today’s colour (#0073AA). The standing brand rule asks for teal #0F766E on primary actions; changing it is outside this story and left to the designer.
  • The Assistant font is not in the checkout, so the pages draw in the font stack’s system-ui fallback.
