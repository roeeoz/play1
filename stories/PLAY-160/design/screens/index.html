Acme home page with a newsletter sign-up banner: screen set

This is the complete set for PLAY-160, which PLAY-161 builds as qa/s5-banner.html. The page is rebuilt from the attached screenshot QA-20261108-S5-home-page, and the approved prototype's banner is added directly under "Welcome to Acme". Every screen has a desktop page and a phone page. Following the approved structure, the page has no loading or error state, because it is static with no backend and no network call. It also has no success or confirmation state (AC 3). A dark strip at the top of each page is a review aid, not part of the design.

Choices made

  • Position, copy and behaviour follow the structure's defaults, as approved in the prototype: the banner sits directly under the heading, holds only the field and Subscribe, shows no invalid-email state, and keeps the typed text after Subscribe.
  • Mobile is derived, not sourced. The screenshot is desktop only, so the phone pages keep the same parts, order and colours. The top bar is tighter (16px gutter, 14px nav), the heading is 32px, the field sits above a full-width Subscribe button, and the feature cards stack into one column.
  • Build hints for PLAY-161: the banner is a plain <div role="group">, not a <form>, and the button is type="button", so pressing Subscribe or Enter never submits, reloads or sends anything (R4). The input has a visually hidden "Email address" label and autocomplete="off".
  • The nav items and Shop now are drawn as in the screenshot but have no targets, because they are outside this story.
