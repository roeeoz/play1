Acme home page with a newsletter sign-up banner

This prototype rebuilds the existing Acme home page from the attached screenshot QA-20261108-S5-home-page and adds one thing: a newsletter banner directly under the hero heading "Welcome to Acme", with an email field and a Subscribe button. Everything else matches the screenshot. Nobody is actually signed up, so pressing Subscribe shows no success message and no confirmation screen (PLAY-160, AC 2 and AC 3). A dark strip at the top of each page is a prototype aid, not part of the design.

Screens

  1. Home page — banner, default. What changed from today: a new banner sits between the heading and the tagline, with an empty field showing the neutral helper text "Your email address" and a Subscribe button. The top bar, tagline, Shop now, cards and footer are unchanged.
  2. Home page — banner, email typed. What changed from today: same banner, with the field focused and showing an address the visitor typed (sample: reader@example.com, a reserved test domain).
  3. Home page — after Subscribe. What changed from today: only the banner. After the press the page looks the same and shows no message. Variant: Subscribe pressed with an empty field.

Paths

  • Default → click the field → Email typed → Subscribe → After Subscribe → "Type again" goes back to Email typed.
  • Default → Subscribe with the field empty → After Subscribe (empty variant).
  • Email typed → "Clear the field" → back to Default.

Choices made (defaults from the approved structure)

  • Position: directly under "Welcome to Acme", above the tagline (open branch 1, default).
  • No invalid-email state is drawn (open branch 2).
  • After Subscribe the typed text stays and nothing else happens (open branch 3).
  • The banner holds only the field and Subscribe: no heading or extra copy, desktop width only (open branch 4).
  • Subscribe uses the top-bar blue, so it doesn't compete with the orange Shop now button. The banner uses a light tint of the same blue.
  • Typing can't be simulated without scripts, so clicking the field moves to the "email typed" page. The nav links and Shop now are drawn but not clickable, because they are outside this story.
