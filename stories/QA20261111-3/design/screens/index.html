play1 greeting banner — screen set

The complete screen set for story QA20261111-3: one screen, the play1 home page with the greeting banner “Hello from play1” at the very top. The approved structure names a single state for it, default; the banner is static text with no input, no data loading and no list, so it has no loading, error or empty state, and none is drawn. Each state is shown as a desktop page and a phone-width (390 px) page. The layout, colours and copy are those of the approved prototype.
