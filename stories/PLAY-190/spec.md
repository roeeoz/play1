# טיוטת סיפור (בקליטה) — PLAY-190: פונקציית ברכה ב-Python ובדיקה שמוודאת אותה

**סטטוס:** NOT_READY — טיוטה בקליטה. הסיפור מתנגש בשער של המאגר (ראו סעיף 6), וזה צריך הכרעה לפני שכותבים את המפרט.

## 1. סקירת היכולת

- **מה מבוקש (כלשון הכרטיס):** מודול Python קטן `qa/s2_hello.py` עם פונקציה `greet(name)` שמחזירה את המחרוזת `'Hello, <name>!'`, ובדיקת pytest בקובץ `qa/s2_hello_test.py`. אסור לגעת בשום קובץ אחר.
- **הבעיה:** סיפור QA של מסלול המפעל (QA-20261122-S2) — השינוי הקטן ביותר שאפשר להעביר דרך המפעל מקצה לקצה, כמו הסיפורים הקודמים PLAY-172 ו-PLAY-175.
- **משתמשים:** המפתח ומנהל המוצר שמריצים את בדיקת המפעל. לפונקציה אין משתמשי קצה.

## 2. מטרות ומה מחוץ לתחום

### מטרות

- `greet(name)` מחזירה ברכה מדויקת לשם שאינו ריק, ודוחה שם ריק בשגיאה ברורה.
- בדיקת pytest מוודאת את שתי ההתנהגויות.
- השינוי קטן ומבודד: שני קבצים חדשים בלבד (בכפוף להכרעה על המיקום, ראו סעיף 6).

### מחוץ לתחום

- כל קובץ אחר במאגר: החבילה `src/testbed_utils`, הבדיקות הקיימות, `pyproject.toml` והגדרות ה-CI.
- פקודת שורת פקודה (CLI) לברכה — לא התבקשה.

## 3. דרישות פונקציונליות

- **FR1:** `greet(name)` מקבלת שם ומחזירה בדיוק `'Hello, ' + name + '!'` — למשל `greet('Ada')` מחזירה `'Hello, Ada!'`.
- **FR2:** `greet('')` זורקת `ValueError` עם ההודעה `'name must not be empty'`.
- **FR3:** בדיקת pytest מכסה את FR1 ואת FR2.
- **לא מוגדר עדיין (שאלה P1):** שם שמכיל רק רווחים (`'   '`) — האם הוא "ריק"?

## 4. חוויית משתמש והתנהגות

- המשתמש הוא מפתח שקורא ל-`greet` מקוד Python: מקבל מחרוזת, או `ValueError` עם ההודעה המדויקת שלמעלה.
- אין ממשק, פלט למסך או דרישות מראה.

## 5. Acceptance Criteria

1. greet('Ada') returns exactly 'Hello, Ada!'.
2. greet('') raises ValueError with the message 'name must not be empty'.

## 6. תלויות ואילוצים

- **התנגשות בשער המאגר (חוסם):** שער המאגר `.factory/plugins/claims-dev/skills/repo-gate/SKILL.md`, כלל 1, קובע: "Python source lives under `src/`; tests live under `tests/`". שני הקבצים שהכרטיס מבקש (`qa/s2_hello.py`, `qa/s2_hello_test.py`) הם Python מחוץ ל-`src/` ול-`tests/`, ולכן כל בקשת מיזוג כזו תיחסם בממצא `PLAY-G1`. השער רץ על כל בקשת מיזוג ואינו קורא את הכרטיס, ולכן אין לו פטור.
- **שער הבדיקות לא יריץ את הבדיקה:** `pyproject.toml` מגדיר `testpaths = ["tests"]`, ו-`.factory/testing.md` קובע ש-`pytest` מתיקיית השורש הוא שער הבדיקות היחיד. בדיקה ב-`qa/` לא תורץ ב-CI, ולכן אף קריטריון לא יוכח בהרצה של השער.
- **תקדים במאגר:** בסיפורים קודמים הסקריפטים ב-`qa/` היו shell, ובדיקות ה-Python שלהם ישבו ב-`tests/` (למשל `tests/test_qa_s3_greeting.py`). פונקציה דומה קיימת כבר ב-`src/testbed_utils/hello.py` ונבדקת ב-`tests/test_hello.py`.
- **"אין לגעת בשום קובץ אחר":** מגביל כל פתרון שדורש שינוי בקובץ קיים (למשל `pyproject.toml` או השער עצמו) בתוך הסיפור הזה.
